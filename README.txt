MATHS ARENA — STAGE 1
======================

What is included:
- Responsive cream / notebook-inspired home page
- Separate Mathematics Part I and Part II chapter indexes
- Chapter selection dialog with Tutorial and Question Practice entry points
- Placeholder dialogs for future Analysis and Settings modules

Textbook chapter lists:
Part I:
1. Linear Equations in Two Variables
2. Quadratic Equations
3. Arithmetic Progression
4. Financial Planning
5. Probability
6. Statistics

Part II:
1. Similarity
2. Pythagoras Theorem
3. Circle
4. Geometric Constructions
5. Co-ordinate Geometry
6. Trigonometry
7. Mensuration

Run:
- Extract this ZIP.
- Open the extracted folder in your Android code editor.
- Open index.html or use the editor's local preview/server if available.
- If the editor preview does not load CSS/JS correctly, use its local server option.

Important:
This is Stage 1 (home page + chapter navigation), not the completed app.
Tutorials, question generation, answer checking, drawing tools, progress storage,
sound and animations are planned for later stages.
The Google Fonts import is optional; if offline, the page uses fallback fonts.
